# Plant QR Science Guide

Bilingual Arabic/English plant profile site for six photographed plants.

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Pages

- `/`
- `/plant/catharanthus-roseus`
- `/plant/dracaena-sanderiana`
- `/plant/dracaena-fragrans`
- `/plant/dracaena-trifasciata`
- `/plant/zamioculcas-zamiifolia`
- `/plant/dracaena-trifasciata-golden-hahnii`

GitHub Pages is deployed by `.github/workflows/deploy.yml`.
